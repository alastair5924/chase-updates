# Chase Windows updates

Windows x64 installers and signed update metadata for Chase.

This repository contains release downloads only. It contains no athlete data, account credentials, private signing keys or application source code.

Install the latest Windows release once. Subsequent releases are offered in Chase through Update & restart. The updater verifies release signatures and package checksums and waits for active work before installing.

The signed update feed is separate from Microsoft Authenticode; the initial Windows installer currently has no trusted-publisher certificate.
